# Local fonts

IBM Plex Sans and IBM Plex Mono supply the shared interface typography.
Their licenses are adjacent to the font files.

Agent Anatomy uses Oxanium SemiBold only for the role and physical-component
headings. Body copy and controls retain IBM Plex Sans; code and evidence values
retain IBM Plex Mono. This local exception does not change the global design system.

Oxanium by Sev Meyer: https://github.com/sevmeyer/oxanium
Source: https://raw.githubusercontent.com/sevmeyer/oxanium/master/fonts/ttf/Oxanium-SemiBold.ttf
License: SIL Open Font License 1.1, see LICENSE-Oxanium.txt.
The 28,892-byte static font is served locally, with no external font requests.

## Work Sans

The product display face is Work Sans (variable weight), self-hosted from the
[Google Fonts source](https://github.com/google/fonts/tree/main/ofl/worksans).
Its SIL Open Font License is bundled as LICENSE-WorkSans.txt.
