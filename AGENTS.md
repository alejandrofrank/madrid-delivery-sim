# Project instructions

## Shell

- Always use Bash for shell commands, scripts and documentation examples.
- Do not use PowerShell unless the user explicitly requests it.
- Prefer `python3` in Bash; Make accepts `PYTHON` for an explicit interpreter.

## Design

- Never default to oversized marketing headlines, split-color headline text,
  gradients in headlines or decorative hero sections.
- Labs, demos and engineering tools should prioritize function, technical depth,
  clear controls and inspectable evidence. Keep the title compact and the working
  interface near the top.
- Use color to communicate state, differences or data.

## Change history and repository

- Commit each coherent, verified change separately with a descriptive message.
- Push verified commits to `alejandrofrank/madrid-delivery-sim`; the user has given
  standing authorization. Keep the repository private unless explicitly requested.
- Exclude credentials, private Terraform variables, state and plans from Git.
