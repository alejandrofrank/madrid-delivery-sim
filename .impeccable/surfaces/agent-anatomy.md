# Agent anatomy

Mode: Read. Audience: hiring managers and clients seeking a short explanation of
each agent, followed by source-backed engineering evidence. The user specified
SVG machines with eleven selectable parts and a connected team view. This is a
code-led extension of the established graphite/Plex/cyan system, not a new identity.

THESIS: Understand an agent by inspecting the parts that give it bounded behavior.
FIRST VIEWPORT: Compact chapter title, all nine role machines in a horizontally
scrollable team, then the selected agent's machine beside an explanation panel.
SIGNATURE INTERACTION: Selecting a physical machine part exposes its real manifest,
runtime defaults or dated evidence. Replay briefly animates the relevant handoffs.
CONSTRAINTS: No paid calls, no invented metrics, no unrelated workspace restyling.
Desktop retains the machine and inspector together. Mobile stacks them, provides
a native selector, and keeps the team in its own scroll region. Reduced motion
disables animated connections. Links open the existing source reader or chapter.
